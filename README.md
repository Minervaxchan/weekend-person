# 周末人格图鉴 · 小红书小工具

此项目只面向小红书小工具容器。交付物是包含本地 HTML / CSS / JS / 图片的 ZIP，不使用 Sites、不需要网站域名、服务端或外部 CDN。

收到发布确认后，以当前 `dist/` 生成小工具 ZIP 和源码 ZIP。日常界面调整只更新项目和本机预览。

## 生成小工具交付包

开发环境需要 Python 3.9+、Node 22+。小工具运行本身不依赖 Python、Node 或任何第三方包。

```sh
node --test tests/*.test.cjs
python3 -m unittest discover -s tests -p 'test_*.py'
python3 tools/package.py
```

本机若没有 PATH 中的 Node，可以通过 `MINITOOL_NODE_BINARY` 指定已安装的 Node 可执行文件。检查器优先使用开发环境的 Acorn，再使用 Node 自带的 Acorn，按 ES2017 经典脚本语法解析；不会下载依赖或将检查器加入上传包。

输出文件：

- `outputs/weekend-persona-xhs-candidate.zip`：小红书小工具候选包，ZIP 根目录是 `index.html`，完整包含四个外置经典脚本、样式、九张黏土插画、页头标识与八枚 SVG 人格徽章。
- `outputs/xhs-package-audit.json`：逐文件大小、SHA-256、语法检查结果、包校验结果及未完成的验证项。
- `outputs/weekend-persona-xhs-source.zip`：开发源码、说明与测试，不用于小工具上传。

打包前自动校验单一入口、文件白名单、包内引用、外置脚本、静态首屏、ES2017 语法和禁用能力；出现错误会停止打包。生成 ZIP 采用固定排序、时间与权限，可以复现同一份产物。

**候选包已经过公开文档检查，不代表通过上传页当期 Skill 的最终校验。** 官方文档要求从小工具上传页取得当前完整改写口令，按其指定 Skill 完成最终检查、修复与打包，再进入上传页第二步。真机预览、审核与上架在小红书完成。

## 单屏与滑动答题

所有页面跟随小工具实际可用视口高度，不使用纵向滚动。短屏会缩小或移除装饰内容，主要操作始终保留。图鉴以双列四行显示全部八种人格；结果页保留人格名、金句、标签和图片操作，介绍页保留一句周末建议。

第一题从单张卡开始。选中答案后左滑或点“下一题”，当前卡翻成彩色牌背，斜着叠到下一张卡后面。到第八题时，七张牌背呈扇形展开。右滑或点“上一题”会从牌堆中取回前一题，保留原答案。末题确认后播放 2.6 秒揭晓动画，播完进入结果。未选答案时无法前进，拖动距离不足时卡片回弹。切换期间锁定选项与导航，系统开启减少动态效果时直接换题，揭晓页短暂停留后显示结果。

页面底色取自对应插画的空白边缘：首页为蓝天到暖黄渐变，结果与人格介绍使用各自场景配色，图片取消圆角外框并柔和衔接到页面。答题卡内部、图鉴图文区域和 1080 × 1440 分享卡同步使用同一配色。原图无需额外处理，仍为包内预渲染素材。

视觉组件采用收藏图鉴风格：页头为云朵翻书标识；八种人格各有一枚彩色徽章、固定编号与对应生活场景；图鉴、人格介绍、结果和分享卡复用同一徽章。徽章是包内静态 SVG，不依赖额外库。短屏隐藏图鉴的次要说明，保留徽章、角色、人格名和本次结果标记。全部操作按钮和导航入口使用纯文字，保留答题字母及选中圆点。

## 页面和模块

每次开启或重测都会洗牌题目和各题选项。当前作答顺序随草稿保存，返回修改和继续测试时沿用。计分使用原题与原选项的对应关系。

- `#home` 首页，支持恢复草稿；静态 HTML 在脚本运行前就显示标题、用途和加载状态。
- `#quiz` 单题四选项、上一题、进度与结果计算。
- `#result` 最近一次实际测试结果。
- `#preview` 当前结果的 1080 × 1440 PNG 预览。
- `#atlas` 八种人格，标记本次测得结果。
- `#persona/<id>` 人格介绍，浏览不会覆盖自己的结果。

所有运行文件都在 `dist/`。`data.js` 管理题库与人格内容，`platform.js` 管理平台接口，`poster.js` 生成人格卡，`app.js` 管理页面交互。`style.css` 包含布局回退及系统安全区适配。插画位于 `dist/assets/`，始终使用包内路径。

## 平台能力

依据 [小红书小工具官方开发文档](https://miniapp-sandbox.xiaohongshu.com/minitool/doc)，核查日期 2026-11-14。

| 操作 | 平台调用 | 处理方式 |
| --- | --- | --- |
| 关注作者 | `getFollowStatus` / `followAuthor` | 9.51+；平台绑定当前作者；处理已关注、本人、取消和限频 |
| 保存相册 | `writeTempFile` → `saveImageToPhotosAlbum` | 9.42+；真实成功才提示已保存，权限拒绝保留预览 |
| 图片分享 | `writeTempFile` → `share` | 9.53+、全屏容器；指定图片用于站内私信，不把回调算作送达 |
| 发布笔记 | `writeTempFile` → `postNote` | 带入同一人格卡及可编辑文案；9.43 以下不传 `pageType` |
| 本机记录 | `getStorage` / `setStorage` / `removeStorage` | 9.46+ 优先平台存储；旧版兼容 localStorage；升级时迁移且清理旧副本 |
| 安全区 | `getWindowInfo` | 9.49+；按实际原生按钮矩形避让；不可用时使用受支持的系统安全区样式 |

临时文件每次操作时重新准备，不持久化文件句柄。接口不可用或客户端版本不符时禁用相应操作并展示说明，不阻断答题。原生关注确认、相册授权、笔记编辑均由用户主动发起；取消后不重复唤起。

## 开发检查

本机页面检查仅用于开发，不生成在线站点或站外用户入口：

```sh
python3 tools/devserver.py
```

普通浏览器未注入小红书 SDK，平台按钮会显示不可用，不模拟操作成功。正式验收使用小红书模拟器和 iOS / Android 真机，尤其检查关注关系、相册系统授权、半屏分享、发布笔记、安全区和 Chrome 61 基线。

产品页面不展示“请在小红书内使用”等环境说明或重复的分享提示，保留具体版本限制和操作失败反馈。

开发预览默认仅监听 127.0.0.1:4173，可用 `--port 4174` 指定现有端口。开发服务器为脚本和样式引用附带本地文件版本，并禁用缓存，避免刷新仍看到旧排版；这些处理不会写入 `dist/` 或小工具上传 ZIP。

历史网页预览产物已放入 `outputs/previous-web-delivery/`，不再由当前打包流程生成，也不会加入小工具 ZIP。视觉素材和已导出的八张人格卡保留。
