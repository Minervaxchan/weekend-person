# 小红书小工具适配记录

依据：[官方小工具开发文档](https://miniapp-sandbox.xiaohongshu.com/minitool/doc)，核查日期 2026-11-14。

| 公开规范 | 本项目调整与检查 |
| --- | --- |
| 单一根入口、经典外置脚本、无内联事件 | ZIP 根目录 `index.html`，四个 `defer` 经典脚本；HTML 解析器拒绝内联脚本、模块和事件属性 |
| Android 8.1 / Chrome 61、ES2017 | 按 ES2017 解析所有发布 JS；检查禁用能力与后续 API；单屏使用基础 flex/grid 布局，按实际视口和原生安全区分配高度；支持减少动态效果偏好 |
| 静态首屏与分阶段初始化 | 入口直接包含产品名、标题、用途和加载状态；平台能力和草稿读取后开放交互，初始化失败可重试 |
| 不直连外网、资源完整入包 | 图像及样式均使用包内路径，无外部 SDK、字体、服务端接口或 CDN |
| 平台可能按需分发 assets | 图片加载失败展示重试入口，允许恢复；海报加载失败保留文字结果并允许重试 |
| 笔记/相册/分享支持本地媒体 | 优先调用 writeTempFile，随即把不透明句柄传入相应接口；方法缺失时保留文档允许的 Data URI 降级 |
| 9.43+ 才支持 postNote.pageType | 旧版基础发笔记调用不携带该字段 |
| 保存、关注、分享由用户主动触发 | 不自动弹关注或分享，不以操作解锁结果；原生编辑/确认期间保持操作锁 |
| 分享仅全屏可用；指定图用于私信 | 处理 15502 等错误；界面说明站内好友分享，站外原图采用先保存的路径 |
| 关注状态和原生坐标由平台提供 | 按 follow_status 更新；按 getWindowInfo 中真实矩形计算避让，无固定坐标阈值 |
| 平台存储及升级迁移 | 原生无数据时迁移旧记录，业务错误不视作无数据；清除时同步移除旧副本 |
| 完整 ZIP、支持的文件类型、无源码映射 | 专用校验器检查白名单、引用、单一入口；清点所有资源及哈希，不包含站点配置、测试或源码映射 |

## 验证边界

本记录是公开规范的实现映射，不是官方平台签发的检查结果。上传页当前完整改写口令及其 Skill 尚未提供，因此 `upload_page_skill_check` 标记为待执行。小红书模拟器、iOS / Android 真机、审核和用户内测均不能由本机自动检查替代。
